## Data

### `individual_abalone_data.csv`
Individual-level records for 107,166 abalone across 12 tanks (4 tanks per diet). Each row represents one detected abalone at trial end. 

A full data dictionary is provided in `individual_abalone_metadata.csv`.

### `per_capita_feed.csv`
Daily records of feed delivered per tank (kg) and estimated live animal counts for each tank across the 131-day trial, used to calculate cumulative per-capita feed availability.

### `heavy_metals.csv`
Heavy metal concentrations (Arsenic, Cadmium, Lead, Mercury, Iron; mg/kg wet weight) measured in viscera and foot tissue from one pooled sample per tank at trial end. Lead values below the limit of detection are recorded as `<0.01`.

---

## Code

### `Bayesian_models.R`

Standalone R script for inspecting, cleaning, and running Bayesian models on abalone weight data.

### `economic_modelling.R`

Standalone R script for building break-even Ulva meal price distributions, and a probability-of-profit curve across a range of Ulva meal prices.

### `heavy_metal_analysis.R`

Tests for differences in heavy metal concentrations between dietary treatments in viscera and foot tissue.
