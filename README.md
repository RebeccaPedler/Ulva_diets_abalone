## Data

### `individual_abalone_data.csv`
Individual-level records for 107,166 abalone across 12 tanks (4 tanks per diet: control, Ulva, wakame). Each row represents one detected abalone at trial end. Tank E01 is excluded from all downstream analysis in both `Bayesian_models.R` and `economic_modelling.R` due to a TGP (total gas pressure) spike confound in late January.

A full data dictionary is provided in `individual_abalone_metadata.csv`.

### `individual_abalone_metadata.csv`
Data dictionary for `individual_abalone_data.csv`: one row per column, giving data type, units, and a description.

### `per_capita_feed.csv`
Daily records of feed delivered per tank (kg) and estimated live animal counts for each tank, across the 131-day trial. Feed is delivered at a fixed daily ration per tank; per-capita feed is derived each day as feed delivered divided by the estimated live count for that tank, and summed across all 131 days to produce the cumulative `per_capita_feed` value reported in `individual_abalone_data.csv`.

### `per_capita_feed_metadata.csv`
Data dictionary for `per_capita_feed.csv`: one row per column, giving data type, units, and a description, in the same format as `individual_abalone_metadata.csv`.

## Code

### `Bayesian_models.R`

R script for inspecting, cleaning, and running Bayesian models on abalone weight data. Fitted models are saved to `models/` for use by `economic_modelling.R`.

### `economic_modelling.R`

R script for building break-even Ulva meal price distributions, and a probability-of-profit curve across a range of Ulva meal prices, using the primary growth model (`fit_weight_final.rds`, adjusted for per-capita feed and starting weight). This script loads the pre-fitted model from `models/` rather than refitting it, so `Bayesian_models.R` must be run first (with `refit <- TRUE`) to generate a complete set of `.rds` files before this script will run.

## Outputs

`outputs/` currently contains:

| File | Generated by |
|---|---|
| `ulva_premium_curve.csv` | `economic_modelling.R` — diet premium vs. Ulva meal price (Part B) |
| `ulva_sgr_economic_summary.csv` | `economic_modelling.R` — SGR, days-saved and break-even summary (Part C1) |
| `ulva_sgr_saving_curve.csv` | `economic_modelling.R` — probability-of-positive-saving curve (Part C2) |
| `ulva_harvest_sensitivity.csv` | `economic_modelling.R` — break-even sensitivity to harvest target weight (Part D) |
| `ulva_breakeven_by_opexshare.csv` | `economic_modelling.R` — break-even Ulva meal price across feed-opex-share x harvest-weight grid (Part D) |
| `ulva_p95_by_opexshare.csv` | `economic_modelling.R` — 95%-probable-profitable Ulva meal price across the same grid (Part D) |

These six files correspond one-to-one with the `write.csv()` calls at the end of `economic_modelling.R`, so a fresh run of the current script reproduces the full contents of this folder.
