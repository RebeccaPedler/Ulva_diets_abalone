## Data

### `individual_abalone_data.csv`
Individual-level records for 107,166 abalone across 12 tanks (4 tanks per diet: control, Ulva, wakame). Each row represents one detected abalone at trial end. A full data dictionary is provided in `individual_abalone_metadata.csv`.

### `individual_abalone_metadata.csv`
Data dictionary for `individual_abalone_data.csv`

### `per_capita_feed.csv`
Daily records of feed delivered per tank (kg) and estimated live abalone counts for each tank, across the 131-day trial. Feed is delivered at a fixed daily ration per tank; per-capita feed is derived each day as feed delivered divided by the estimated live count for that tank, and summed across all 131 days to produce the cumulative `per_capita_feed` value reported in `individual_abalone_data.csv`.

### `per_capita_feed_metadata.csv`
Data dictionary for `per_capita_feed.csv`

## Code

### `Bayesian_models.R`

R script for inspecting, cleaning, and running Bayesian models on abalone weight data. Fitted models are saved to `models/` for use by `economic_modelling.R`.

### `economic_modelling.R`

R script for building break-even Ulva meal price distributions, and a probability-of-profit curve across a range of Ulva meal prices, using the primary growth model (`fit_weight_final.rds`, adjusted for per-capita feed and starting weight). This script loads the pre-fitted model from `models/`, so `Bayesian_models.R` must be run first (with `refit <- TRUE`) to generate a complete set of `.rds` files before this script will run.

## Outputs

`outputs/` contains:

| File | Generated by |
|---|---|
| `ulva_wakame_premium_curve.csv` | `economic_modelling.R` — diet premium vs. algal meal price, Ulva and wakame (Part A) |
| `ulva_sgr_economic_summary.csv` | `economic_modelling.R` — SGR, days-saved and break-even summary at the actual meal price (Part B) |
| `ulva_sgr_saving_curve.csv` | `economic_modelling.R` — probability-of-positive-saving curve across Ulva meal price (Part C2) |
| `probability_break_evens.csv` | `economic_modelling.R` — highest Ulva meal price at each profitability confidence level (Part C2) |
| `days_by_target_df.csv` | `economic_modelling.R` — days-saved sensitivity to harvest target weight (Part D) |
| `ulva_breakeven_by_confidence.csv` | `economic_modelling.R` — break-even Ulva meal price at 50%, 95% and 99% confidence, across the feed-opex-share x harvest-weight grid (Part D2)
